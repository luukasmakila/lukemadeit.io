# lukemadeit.io

Personal website and portfolio for Luukas Mäkilä. This project is built with modern web tools and is designed to be fast, accessible, and easy to maintain.

## Technology stack

- Node.js and npm
- React
- TypeScript
- Vite
- ESLint & Prettier (if configured in the repo)

# # Getting started

Prerequisites:

- Node.js (LTS recommended)
- npm

## 1) Clone the repository

```bash
git clone https://github.com/luukasmakila/lukemadeit.io.git
cd lukemadeit.io
```

## 2) Install dependencies

```bash
npm install
```

## 3) Run the development server

```bash
npm run dev
```

Open the local url shown in the terminal (usually `http://localhost:5173`).

## 4) Build for production

```bash
npm run build
```

The production build output will be generated in the `dist`/` folder.

## 5) Preview the production build locally

```bash
npm run preview
```

## Available scripts

- `npm run dev` – Starts the development server
- `npm run build` – Creates a production build
- `npm run preview` – Serves the production build locally
- `npm run lint` – Runs linting (if available)

## Project structure (igh-level)

- `src/` – Application source code
- `public/` – Static assets
- `package.json` – Project scripts and dependencies
